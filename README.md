# Hotstar-Clone-Project 🎊
A simple Hotstar clone built using HTML and CSS. It features:
<br>
1) A visually appealing homepage with a navigation bar. <br>
2) Sections for featured movies, shows, and categories 📺. <br>
3) Responsive design for desktop💻 and mobile devices📱. <br>

This project focuses on replicating the UI for learning purposes and improving web development skills.
